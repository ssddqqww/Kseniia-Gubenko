# Kseniia Gubenko Portfolio

An original, responsive portfolio website built around Kseniia's work in computer science, AI research, cybersecurity, and educational technology.

## Run locally

```bash
npm run dev
```

Open `http://127.0.0.1:4173`.

## Structure

- `index.html` - portfolio content and semantic structure
- `styles.css` - responsive visual system
- `script.js` - navigation, reveal effects, copy-email action, and interactive project cards
- `assets/` - reserved for the final portrait and project imagery
- `CONTENT_NOTES.md` - source reconciliation and facts that need confirmation

The site is static and can be deployed directly to Vercel without a build step.
